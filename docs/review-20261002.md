# Проверка программы перед сдачей

Дата повторной проверки: 2 октября 2026 года. Проверены исходники рабочей версии, тесты, реальные E5/CUDA-сценарии и сохранённые результаты первого этапа. Полная серия оптимизации в эту проверку не входит.

## Заключение

Базовая версия работоспособна в текущем окружении. Проверенные сценарии не выявили блокирующих дефектов. Это вывод в пределах перечисленных тестов, а не подтверждение промышленной готовности.

Для полного выполнения индивидуального задания ещё требуется доказать результат GPU-оптимизации: провести сравнительную матрицу, профилирование и выбрать конфигурацию по измерениям. Наличие GPU и поддержки FP16 само по себе не доказывает ускорения.

## Оставшиеся ограничения

1. Нет полной матрицы 8/16/32/64/128 × FP32/FP16 и профиля CPU/GPU. Нет выбранной лучшей конфигурации.
2. 32 размеченных вопроса относятся к коротким демоинструкциям. Hit@5=1 не доказывает качество на реальных университетских документах и не оценивает отказы на посторонние вопросы.
3. Истощение GPU-памяти проверено моделированием ошибки; реальное OOM намеренно не вызывалось. Нет продолжительного нагрузочного теста и чистой установки на другом компьютере.
4. Сложная вёрстка PDF и вложенные объекты DOCX могут извлекаться неполно. OCR исключён из объёма. Есть исходные файлы для ручной сверки.
5. Новая версия рассчитана на одного локального пользователя. Многопользовательская работа, промышленное внедрение и организационная экономия не проверялись.

## Повторение проверок

Из корня проекта после установки:

```powershell
.\.venv\Scripts\python.exe scripts/check_sources.py
.\.venv\Scripts\python.exe -m ruff check app
.\.venv\Scripts\python.exe -m pip check
cd app
$env:NAVIGATOR_REAL_GPU = '1'
..\.venv\Scripts\python.exe -m pytest -q
```

Без CUDA и локальной модели не задавайте `NAVIGATOR_REAL_GPU`: тяжёлые проверки будут явно пропущены. [Установка и запуск](../app/INSTALL.md), [методика экспериментов](../app/docs/EXPERIMENTS.md), [преемственность кода](../app/docs/MIGRATION.md).
