Завершено 12 сентября 2026 года. Реализована базовая версия «Интеллектуального навигатора по документам университета» в `app/`. Word-отчёт не заполнялся. Летний снимок и три файла материалов сохранены без изменений.

## Среда

Проверена локальная Windows 11, Python 3.12.14 в отдельной `.venv`. Системный Python 3.14.6 не изменялся. Для создания окружения использован установленный комплектный Python 3.12; при самостоятельной установке подойдёт обычный Python 3.12 x64.

- NVIDIA GeForce RTX 4080 SUPER, доступная видеопамять устройства по PyTorch 16375.5 МиБ.
- Драйвер 595.97; PyTorch 2.8.0+cu128, CUDA runtime 12.8. `torch.cuda.is_available()` вернул `true`; матричное умножение действительно выполнено на CUDA.
- Физическая память по psutil: 31.115 ГиБ (компьютер заявлен как 32 ГБ).
- Sentence Transformers 5.1.2, Transformers 4.57.1, Streamlit 1.50.0, NumPy 2.2.6.
- E5: `intfloat/multilingual-e5-small`, ревизия `614241f622f53c4eeff9890bdc4f31cfecc418b3`.

Машиночитаемая среда: [environment.json](validation/environment.json). Полный список установленных пакетов: [environment-freeze.txt](environment-freeze.txt). Обычные зависимости закреплены в `app/constraints-windows-py312.txt`, CUDA/CPU-сборка torch выбирается отдельно.

Основные команды из папки `app`:

```powershell
$env:NAVIGATOR_REAL_GPU = '1'
..\.venv\Scripts\python.exe -X utf8 -m pytest -q --basetemp=../tmp/stage1-final --junitxml=../docs/test-results-all.xml
..\.venv\Scripts\python.exe -m ruff check .
..\.venv\Scripts\python.exe -m pip check
```

В начале проверки стандартная временная папка `Temp/pytest-of-VV` оказалась недоступной; повторный запуск с расширенными правами этого не исправил. В конфигурацию тестов добавлена выделенная временная папка внутри проекта и отключён кэш pytest; после этого все проверки выполнены. Ошибки первого запуска не трактуются как успешные тесты. Два оставшихся предупреждения — DeprecationWarning типов SWIG из зависимости, не ошибки тестов.

Полная повторная установка `setup.ps1` в ещё одно чистое окружение не выполнялась: зависимости установлены и проверены теми же командами pip, модель скачана реальным скриптом. Самостоятельная установка на другом компьютере остаётся отдельной проверкой переносимости. Исходный CustomTkinter-интерфейс и MiniLM-модель не запускались; для исходника выполнены предусмотренные лексические/SQLite-тесты.

Визуальный рендер DOCX-примера через `render_docx.py` выполнить не удалось: в среде отсутствует `soffice.exe` (LibreOffice). Чтение DOCX, порядок текста и таблиц, индексация и поиск проверены. PDF-пример отрендерен и визуально просмотрен. Это ограничение проверки оформления тестового файла, а не импорта DOCX; отчёт и шаблон не редактировались.
