# План первого этапа

1. Проверить SHA-256 исходного снимка, прочитать исходники и материалы. Скопировать летнюю программу в `app/` перед изменениями.
2. Сохранить и исправить SQLite-слой, импорт JSON и лексические функции. Добавить документы и фрагменты. Для E5 сохранять регистр и пунктуацию; использовать токенизатор модели и префиксы `query: ` / `passage: `.
3. Добавить чтение TXT/DOCX/PDF, привязку к страницам, атомарное сохранение индекса и проверку совместимости с данными, моделью и параметрами.
4. Заменить точку входа и интерфейс на Streamlit с тремя вкладками. Разделить скачивание модели и полностью локальный рабочий режим.
5. Подготовить механизм измерений CUDA FP32/FP16, прогрев, повторы, Hit@5, CSV и графики. Выполнить только базовый контрольный запуск; полная матрица — этап 2.
6. Запустить исходные тесты и новые проверки, реальный поиск и интерфейс. Зафиксировать среду, фактические результаты, преемственность кода и инструкцию Windows.

Материалы и исходный снимок не редактируются. Word-отчёт в этот этап не входит.
