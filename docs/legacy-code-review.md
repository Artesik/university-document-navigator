## Существенные изменения для навигатора

- Старый код индексирует вопрос, альтернативные формулировки, ключевые слова и категорию. Полный ответ и шаги в `_document_text` не входят. При импорте инструкций в новый документный поиск нужно включить содержимое answer/steps в доступный для поиска текст, сохранив исходные значения и идентификаторы.
- Сейчас возвращается одна запись. Для навигатора требуется выдача до пяти фрагментов с корректной привязкой к источнику.
- В просмотренном коде нет чтения TXT/DOCX/PDF, разбиения документов, сохранения эмбеддингов на диск и матрицы GPU-экспериментов.
- Эмбеддинги вычисляются при загрузке модели. Устройство не задаётся явно, размеры пакетов и точность не управляются конфигурацией программы. Это не позволяет утверждать по исходнику, что летняя программа работала только на CPU или на GPU; фактический режим зависит от окружения.
- Имя режима жёстко содержит MiniLM, поэтому простая замена `model_name` без остальных изменений оставит неверную подпись.
- В `database_manager.py` используются блоки `with self._connect()`, явного гарантированного закрытия соединений в показанном коде нет. Проблему управления соединениями из летнего отчёта нужно проверить и устранить в рабочей версии. Конкретная блокировка файла в этой сессии не воспроизводилась.
- Базу `assistant.db` программа создаёт при запуске; в предоставленной папке её нет. Для начала достаточно сохранённого JSON. История пользователей для разработки не требуется.
