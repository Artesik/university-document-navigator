## Воспроизведение

После установки выполните из корня проекта:

```powershell
.\.venv\Scripts\python.exe scripts/verify_package.py
.\.venv\Scripts\python.exe scripts/check_sources.py
.\.venv\Scripts\python.exe -m pip check
.\.venv\Scripts\python.exe -m ruff check app
cd app
$env:NAVIGATOR_REAL_GPU = '1'
..\.venv\Scripts\python.exe -B -X utf8 -m pytest -q
```

Скрипт `verify_package.py` проверяет контрольные суммы переданных файлов; `check_sources.py` — неизменность летней версии. Для двух реальных интеграционных тестов нужны локальная E5 и CUDA. Без переменной `NAVIGATOR_REAL_GPU` эти тесты пропускаются.
