# Проверка окончательного комплекта

Дата: 22 октября 2026 года.

Изменена структура публикации, а не поисковая логика приложения:

- один видимый `README.md` в корне;
- руководство приложения называется `app/INSTALL.md`;
- описание примеров называется `app/examples/EXAMPLES.md`;
- устаревшая папка `app/assets` с памяткой об иконке не включена;
- летний снимок передаётся одним ZIP с сохранением всех 28 файлов;
- FOR_TEACHER и инструкции загрузки исключены из публикуемой папки;
- файл требований и лицензия проекта отсутствуют.

Относительные ссылки Markdown и изображение проверяются при сборке. Манифест FILES.sha256 содержит контрольные суммы файлов комплекта. Скрипт check_sources.py проверяет как исходную папку летнего приложения, так и её ZIP-копию.

Комплект содержит 80 файлов, поэтому его можно загрузить одной партией. ZIP летней версии считается одним файлом для загрузки, внутри него сохранены 28 исходников. Проверка манифеста охватывает 79 файлов; сам FILES.sha256 в него не входит.

Последняя проверка настоящей E5/CUDA выполнена 17 октября: 40 тестов рабочей версии и отдельно 8 тестов летнего снимка прошли. Эти результаты сохранены в [журнале](release-check-20261017.md). Полная серия GPU-оптимизации не проводилась.

22 октября тесты запущены непосредственно из пробной сборки с новой структурой: 38 passed, 2 skipped за 25,53 с. Два пропуска относятся к настоящей E5/CUDA: веса модели намеренно не входят в сдаваемую папку. Проверены также чтение летнего ZIP и совпадение всех 28 файлов с исходным манифестом. Это проверка упаковки в установленном окружении, а не новая чистая установка на другом компьютере.

Факт корректной локальной сборки не подтверждает состояние ранее загруженного репозитория. При обновлении GitHub нужно убрать старые файлы, отсутствующие в новой структуре: простая загрузка поверх существующих файлов их не удаляет.
