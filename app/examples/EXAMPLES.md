# Учебные данные

`library.txt`, `practice.docx` и двухстраничный `document_rules.pdf` — искусственно составленные примеры для проверки импорта. Они не являются действующими документами университета.

`quality_questions.json` содержит 32 вопроса, составленных по содержанию прежних 32 демоинструкций. Разметка задана до первых измерений. Цель — проверить Hit@5 на фиксированной учебной выборке. Это не независимый тест на реальных документах университета. Правильные ID относятся к стандартному разбиению E5 (384 токена, перекрытие 64); при изменении границ их нужно проверить заново. Приложение отвергает разметку с отсутствующими ID.

Для добавленных документов подготовьте отдельные вопросы с точными ID из выдачи. Формат записи: `id`, `query`, `relevant_chunk_ids` (один или несколько правильных фрагментов). Неверный вопрос или отсутствующий ответ не следует размечать как найденный.

На следующем этапе: расширить набор реальными разрешёнными документами, проверить разметку вручную и зафиксировать её до сравнения конфигураций. Искусственные нагрузки 100/1000/5000 фрагментов запускаются отдельно от проверки качества.
