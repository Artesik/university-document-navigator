# Архитектура версии 2

Streamlit (`app.py`, `modules/ui.py`) и CLI (`cli.py`) используют `Navigator` из `service.py`.

Импорт: байты файла → `documents.extract_document` → исходный файл, страницы и метаданные в SQLite (`DatabaseManager`). Импорт демоинструкций использует валидатор JSON и `instruction_text`; исходные поля сохраняются.

Индексация: извлечённые страницы → `chunk_documents` → `E5Encoder` → нормализованные векторы → `index_store` (единый атомарный NPZ). Манифест фиксирует модель, ревизию, параметры и SHA-256 корпуса.

Поиск: проверка совместимости сохранённого индекса → `query: ` + запрос → E5 → скалярное произведение с векторами → до пяти исходных фрагментов и их источники. Страницы не генерируются; для PDF используются исходные номера, для TXT/DOCX — номера фрагментов.

Эксперименты используют те же фрагментацию, encoder и сохранение индекса; работают с отдельными файлами и сохраняют реальные повторы. Подробнее: [EXPERIMENTS.md](EXPERIMENTS.md).

Старые history/feedback и лексические функции оставлены для совместимости и регрессионных проверок. Их присутствие не означает наличие этих функций в новом интерфейсе. Карта преемственности: [MIGRATION.md](MIGRATION.md).
