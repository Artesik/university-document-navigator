# Описание проекта версии 2

«Интеллектуальный навигатор по документам университета» развивает летнего помощника до локального поиска фрагментов TXT, DOCX, PDF и демоинструкций. Тема практики — разработка семантического поиска и оптимизация нейросетевого модуля на GPU.

Устройство: [ARCHITECTURE.md](ARCHITECTURE.md). Преемственность: [MIGRATION.md](MIGRATION.md). Программа остаётся учебным прототипом; реальное внедрение и организационная экономия не заявляются.
