# Развитие летнего приложения

Работа начата с побайтовой копии `legacy-source/synergy-ai-assistant/` в `app/`. Это развитие предоставленных пользователем исходников, а не получение другой версии с GitHub. Снимок из 28 файлов проверяется по `../../docs/legacy-source-manifest.json`; команда из корня: `.venv\Scripts\python.exe scripts/check_sources.py`. Материалы практики также проверяются по отдельным SHA-256 и не редактируются.

| Исходный файл | Что использовано и изменено |
|---|---|
| `app.py` | Сохранена роль точки входа, связывающей интерфейс с модулями. CustomTkinter заменён запуском Streamlit. |
| `modules/database_manager.py` | Сохранены класс DatabaseManager, SQLite, параметризованные запросы, импорт knowledge и преобразование JSON-полей, history/feedback для прежних тестов. Исправлен жизненный цикл: контекст транзакции плюс обязательный `close()` в `finally`. Добавлены документы, исходные байты, извлечённые страницы, атомарный импорт демоинструкций. |
| `modules/search_engine.py` | Сохранены SearchResult, принцип нормализованных эмбеддингов и скалярного произведения, лексические функции и старый SemanticSearchEngine для регрессии/отдельного сравнения MiniLM. На этой основе добавлен DocumentSearchEngine: top-5 фрагментов, явный encoder, источники, без старого порога и автоматического fallback. |
| `modules/text_processing.py` | Сохранены normalize_text, tokenize, char_ngrams для прежнего лексического поиска. Добавлен chunk_documents с окнами по токенизатору E5 и исходными диапазонами символов. Нормализация регистра, ё и удаление стоп-слов не применяются к E5. |
| `_document_text` | Старый вариант остаётся в классе совместимости для воспроизведения лексических тестов. Для навигатора общий `instruction_text` включает question, aliases, answer, steps, keywords, category; он используется импортером и новым поисковым классом. |
| `database/knowledge_base.json` | Перенесён без изменения: 32 записи, 9 категорий. Сохранены все исходные поля и исходный JSON каждой инструкции. Демонстрационный характер обозначается явно. |
| `tests/test_database.py`, `test_search_engine.py`, `test_text_processing.py` | Все восемь исходных тестов сохранены. Дополнены проверками новых сценариев и реального E5/CUDA-режима. |
| `modules/feedback_manager.py` | Сохранён для совместимости старых сервисов; в новом интерфейсе оценки и история пока не используются. |
| `modules/ui.py` | Переработан в три вкладки Streamlit; показ исходной выдержки, источника и подразделения продолжает прежний сценарий. |
| зависимости, setup/run | Переработаны для Python 3.12, Streamlit, CUDA и закреплённой E5. Старая сборка EXE исключена из рабочей версии. |

Добавлены модули `documents`, `embedding`, `index_store`, `service`, `experiments`, `config`, `errors`; CLI, скачивание закреплённой модели, тестовые документы, вопросы, измерения и документация.

Исправление SQLite проверяется не только успешным запросом: тест удерживает ссылку на соединение и убеждается, что оно закрыто; проверяет откат при исключении и переименование/удаление временного файла базы. Сам `with sqlite3.connect(...)` завершает транзакцию, но не закрывает соединение — поэтому прежняя реализация была недостаточной.

В новом рабочем пути нет автоматического перехода на лексический поиск при ошибке модели. Прежний лексический режим оставлен в классе совместимости, его тесты не доказывают работоспособность нейросетевого поиска. MiniLM и E5 не смешивают эмбеддинги или пороги.
