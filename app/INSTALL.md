# Интеллектуальный навигатор по документам университета

Учебный локальный прототип для сентябрьской практики. Программа развивает летнее приложение из `../legacy-source/synergy-ai-assistant/`: импортирует прежние инструкции, читает документы и ищет исходные фрагменты с помощью E5. Генерации ответов LLM и OCR нет.

## Быстрый запуск на этом компьютере

Из корня проекта запустите `app\run.bat`. Откроется браузер с адресом http://127.0.0.1:8501. Завершение: Ctrl+C в окне запуска.

Вручную из PowerShell, открытого в корне проекта:

```powershell
cd app
..\.venv\Scripts\python.exe -m streamlit run app.py
```

На вкладке «Документы» импортируйте 32 демоинструкции и добавьте примеры из `examples/`. Нажмите «Построить и сохранить индекс». Затем откройте «Поиск», задайте вопрос и проверьте источник. После повторного запуска используйте «Открыть сохранённый индекс» или сразу выполните поиск: документы повторно не кодируются.

## Установка в Windows с нуля

Проверяемая конфигурация — **Python 3.12 x64**. Нужен драйвер NVIDIA, совместимый с CUDA 12.8. Отдельный CUDA Toolkit для готового колеса PyTorch не требуется. Установка пакетов и первая загрузка модели требуют интернета; рабочая обработка документов остаётся локальной. Место под окружение, модель и временные загрузки: предусмотрите около 10–15 ГБ.

1. Установите Python 3.12 x64 с официального сайта Python. Если системный `python` указывает на другую версию, передайте полный путь к Python 3.12.
2. В корне проекта выполните:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\app\setup.ps1 -Python "C:\путь\к\Python312\python.exe"
```

Если `python --version` уже показывает 3.12, достаточно `app\setup.bat`. Окружение создаётся в `../.venv` относительно папки `app`; системные пакеты не изменяются. Версии обычных пакетов закреплены в `constraints-windows-py312.txt`, сборка PyTorch устанавливается отдельно.

Для явно обозначенного CPU-режима:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\app\setup.ps1 -Python "C:\путь\к\Python312\python.exe" -Cpu
```

После установки CPU-сборки выберите CPU в интерфейсе. CPU-результаты не сравниваются как CUDA-оптимизация.

Ручные команды, если окружение Python 3.12 уже создано в корне проекта:

```powershell
.\.venv\Scripts\python.exe -m pip install torch==2.8.0+cu128 --index-url https://download.pytorch.org/whl/cu128
.\.venv\Scripts\python.exe -m pip install -r app/requirements-dev.txt -c app/constraints-windows-py312.txt
.\.venv\Scripts\python.exe -X utf8 app/scripts/download_model.py
.\.venv\Scripts\python.exe -X utf8 app/cli.py doctor
```

Не переносите `.venv` между компьютерами: пересоздайте его. Папку `app/models/` можно скопировать после загрузки вместе с манифестом модели. Версия E5 закреплена в `model-lock.json`. Скрипт скачивает файлы этой ревизии и проверяет SHA-256 при повторном запуске; приложение проверяет их перед загрузкой. Только скрипт скачивания использует сеть. `run.bat` дополнительно устанавливает offline-переменные библиотек.

## Возможности и хранение

- «Документы»: TXT (UTF-8, UTF-16 с BOM, Windows-1251), DOCX (основной текст и таблицы), PDF с текстовым слоем. До 25 МБ на файл, до 1000 страниц PDF, до 5 млн символов извлечённого текста. Повторная загрузка того же файла с тем же именем не создаёт дубликат; файл с изменённым содержимым становится отдельным документом. Старый вариант можно удалить в списке.
- Импорт JSON сохраняет поля `id`, `question`, `aliases`, `answer`, `steps`, `source`, `department`, `keywords`, `category`. Ответ и нумерованные шаги входят в поисковый текст. Источник и подразделение показываются отдельно, инструкции помечены как демонстрационные.
- Текст делится на окна по 384 токена с перекрытием 64. Сохраняются исходные подстроки, регистр, пунктуация и «ё». Страницы PDF не объединяются; пустые страницы пропускаются с сохранением исходных номеров. Для TXT и DOCX указывается номер фрагмента, поскольку стабильных страниц у них нет.
- «Поиск»: максимум пять фрагментов по косинусному сходству. Порог MiniLM не переносился. Сходство не является вероятностью правильности; при постороннем вопросе всё равно могут быть показаны ближайшие тексты.
- `data/navigator.db`: SQLite, исходные байты файлов, извлечённые страницы и метаданные. `data/index.npz`: векторы FP32 и JSON, загрузка без pickle. Файл индекса заменяется атомарно; проверяются контрольные суммы, нормализация, размерность, модель, ревизия, параметры и состав документов.
- Изменение корпуса, модели или фрагментации требует перестроения. Устройство и точность запроса могут отличаться от режима построения: это явно указано в выдаче. Для измерений каждая конфигурация заново кодирует весь корпус.
- `data/experiments/<run-id>/`: исходные повторы, разметка, выдача по вопросам и манифест запуска. Эксперименты не заменяют рабочий поисковый индекс.

Для резервной копии остановите приложение и скопируйте `app/data/`. Чтобы использовать отдельную коллекцию, перед запуском задайте `NAVIGATOR_DATA_DIR` (абсолютный путь). Приложение предназначено для одного локального пользователя; одновременные эксперименты из нескольких процессов не предусмотрены.

## Командная строка

Команды ниже выполняются из папки `app`:

```powershell
..\.venv\Scripts\python.exe -X utf8 cli.py doctor
..\.venv\Scripts\python.exe -X utf8 cli.py import-demo
..\.venv\Scripts\python.exe -X utf8 cli.py upload examples/library.txt examples/practice.docx examples/document_rules.pdf
..\.venv\Scripts\python.exe -X utf8 cli.py --device cuda --precision fp32 build --batch 32
..\.venv\Scripts\python.exe -X utf8 cli.py --device cuda search "Как восстановить доступ к кабинету?"
```

Глобальные параметры `--data-dir`, `--device`, `--precision`, `--tokens`, `--overlap` указываются **до** названия команды.

## Проверки и эксперименты

```powershell
cd app
..\.venv\Scripts\python.exe -m pytest -q
$env:NAVIGATOR_REAL_GPU = '1'
..\.venv\Scripts\python.exe -m pytest -q -m real_model
```

Без `NAVIGATOR_REAL_GPU=1` тяжёлые GPU-проверки отмечаются как пропущенные с причиной. Быстрые тесты используют явные тестовые заглушки и временные каталоги; их числа не являются экспериментальными результатами.

Базовый запуск с настоящей E5 и проверкой качества:

```powershell
..\.venv\Scripts\python.exe -X utf8 cli.py --device cuda --precision fp32 benchmark --batches 32 --repeats 3 --warmups 1 --labels examples/quality_questions.json
```

Методика, матрица следующего этапа и границы времени: [EXPERIMENTS.md](docs/EXPERIMENTS.md). Связь с летним кодом: [MIGRATION.md](docs/MIGRATION.md). Выполненные проверки: [stage1-validation.md](../docs/stage1-validation.md).

## Ошибки и ограничения

Если CUDA недоступна, проверьте `cli.py doctor` и `nvidia-smi`: цифра CUDA в `nvidia-smi` обозначает возможности драйвера, а `torch.version.cuda` — сборку PyTorch. При нехватке памяти уменьшите пакет либо освободите GPU; автоматической подмены на CPU или FP16 нет. При повреждении модели повторите скачивание; при повреждении или устаревании индекса перестройте его. При нехватке места прежний индекс сохраняется, если атомарная замена ещё не завершилась.

Сканы PDF требуют отдельного OCR и в этой версии отвергаются. Пустые страницы смешанного PDF пропускаются с предупреждением. В DOCX не извлекаются колонтитулы, текстовые поля и вложенные объекты; в сложных PDF порядок колонок может отличаться от визуального. Таблицы представлены текстом. Обнаруженное извлечение можно проверить в списке документов. Тексты запросов свыше лимита модели отклоняются без молчаливого усечения.

Технические основания: [карточка E5 — префиксы и предел 512 токенов](https://huggingface.co/intfloat/multilingual-e5-small), [локальная загрузка Sentence Transformers](https://www.sbert.net/docs/package_reference/sentence_transformer/model.html), [официальные сборки PyTorch 2.8 для Windows/CUDA 12.8](https://pytorch.org/get-started/previous-versions/).
